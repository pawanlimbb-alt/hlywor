HlyWor: Community Publishing Platform

HlyWor (hlywor.fun) is an independent web publishing platform designed to provide a space for personal essays, blogs, and creative writing. Some things don't fit in a standard conversation, so HlyWor was built to give those stories a permanent home.

Tech stack and features include a Firebase Firestore backend for real-time post database queries, responsive web typography, custom theme rendering, dark fire ambient glow effects, and mobile-first layouts.
